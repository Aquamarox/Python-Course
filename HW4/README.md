# Flask Web Application

Flask-домашка

## Функционал:
- GET / - информация о сервере
- GET /author - информация об авторе  
- GET /sum?a=X&b=Y - сложение двух чисел

## Запуск:
```bash
make venv
make install_requirements
make run
```

## Тестирование:
```bash
make test
```

Сервер доступен по адресу: http://localhost:5000
